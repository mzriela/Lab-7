# Lab-7
In this lab, I learned how to turn an ESP32 into a Wi-Fi Access Point and web server, so a phone or laptop can connect directly to it and view live temperature data from a BMP280 sensor on a browser dashboard. I also learned how to control an LED remotely using HTTP routes, which showed me how client-server communication works in IoT systems.
# Required Equipment
- ESP32 Development Board
- BMP280 Sensor Module
- Breadboard
- LED
- 220 Ω resistor
- Jumper Wires
- USB Cable
# Software
- Visual Studio Code
- PlatformIO
- Serial Monitor
- Smartphone or Laptop Web Browser
# Safety Instructions
- Disconnect power before modifying circuits
- Verify all wiring before powering the circuit
- Ensure all grounds are connected
- Avoid short circuits
- Keep the workstation organized
